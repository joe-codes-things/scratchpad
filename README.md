# ScratchPad Manual

## What It Does

ScratchPad is a multi-notepad plugin for your DAW. Write notes, lyrics, chord progressions, or any text you need while producing music. All notes save with your DAW project.

---

## Controls

### Top Bar

#### Font Size Dropdown

- Changes text size for all notepads
- Range: 8pt to 32pt
- Default: 18pt

#### New Note Button (+)

- Creates a new notepad tab
- New tabs are named "Note 1", "Note 2", etc.

#### Delete Note Button (-)

- Deletes the currently active notepad
- Cannot delete if only one notepad remains

#### Export Note Button (E)

- Saves current notepad as a `.txt` file
- Opens file browser to choose save location
- Filename defaults to the notepad's name

#### Settings Button (⚙)

- Opens menu with:
  - **About**: Shows plugin version and developer info
  - **Style Guide**: Opens NLA visual design documentation

### Note Tabs

#### Click a Tab

- Switches to that notepad

#### Double-Click a Tab Name

- Enables rename mode
- Press Enter or Tab to confirm
- Press Escape to cancel
- Click elsewhere to auto-confirm

### Text Editor

#### Main Area

- Type, edit, and format text freely
- Text persists when you save your DAW project
- Each notepad stores its own content independently

### Nine Lives Audio Text

#### Top Right Corner

- Click to view developer information
- Shows company name and website

---

## Tips

- Each DAW project saves its own set of notepads
- Notepads scroll horizontally if you create many tabs
- Export notes to share with collaborators or archive outside your DAW
- Window is resizable: drag corners to adjust size
