ScratchPad

by Nine Lives Audio

ScratchPad is a multi-notepad plugin for your DAW. Write notes, lyrics, chord progressions, or any text you need while producing music. All notes save with your DAW project.

Want to choose which plugin formats to install? Click Customize (or Custom Install) on the Installation Type screen, then select VST3, Audio Unit (AU), or both. See README.md on the accompanying disk image for project and usage information.

Supported DAWs: Logic Pro, Cubase, and any DAW that supports VST3 or AU plugins on macOS.
