ScratchPad

by Nine Lives Audio

ScratchPad is a multi-notepad plugin for your DAW. Write notes, lyrics, chord progressions, or any text you need while producing music. All notes save with your DAW project.

If you opened this package directly, choose Customize on the Installation Type step to select VST3, Audio Unit (AU), or both. For format checkboxes before installation starts, open ScratchPad Installer.app from the accompanying disk image. See README.md on the disk image for project and usage information.

Supported DAWs: Logic Pro, Cubase, and any DAW that supports VST3 or AU plugins on macOS.
